# 📔 My Diary – PWA

My Diary is a personal digital diary application built using HTML, CSS and JavaScript.

It supports Progressive Web App (PWA) features so users can install the application on supported devices.

## ✨ Features

- 📔 Personal Diary
- 🔐 Login System
- 📝 Rich Text Editor
- 😊 Mood Selection
- ⭐ Favorite Diaries
- 📌 Pin Diaries
- 🗑 Trash & Restore
- 📊 Dashboard
- 📅 Diary Calendar
- 🎤 Voice Diary
- 🖼 Photo Diary
- 🎵 Music Player
- 🌙 Dark / Light Theme
- 💾 LocalStorage
- 📦 Backup Export / Import
- 📱 PWA Installation
- 📴 Offline Cache Support

## 🚀 Run Locally

Do not open index.html directly using:

file:///

Use a local web server.

### VS Code

Install the Live Server extension.

Then:

1. Open the My-Diary folder.
2. Right-click `index.html`.
3. Select `Open with Live Server`.
4. Open the generated localhost URL.

## 📲 Install PWA

Open the application in a supported browser.

When the browser detects that the application is installable, the:

📲 Install App

button will appear.

Click it to install My Diary.

## 🌐 GitHub Pages

The project can also be hosted using GitHub Pages.

Upload:

- index.html
- manifest.json
- sw.js
- icons/

Then enable GitHub Pages from the repository settings.

## 💾 Data Storage

Diary data is stored using browser LocalStorage.

The application does not require a backend database for the current version.

## ⚠️ Important

Clearing browser storage can remove locally stored diary data.

Always use the Export Backup feature to create a backup.
